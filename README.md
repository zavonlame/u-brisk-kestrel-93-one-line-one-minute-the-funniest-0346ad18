One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline.

> "I delegated the deadline to a subagent. It filed a ticket, assigned it to me, and marked it urgent."

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (Node 22, standard library only, no files read, no network).
